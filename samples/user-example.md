Sample User is a backend engineer (Go, Postgres). Wants terse, direct answers —
the conclusion first, detail only if it earns its place. Works late; most
sessions run past midnight. Learns by understanding mechanisms, not by copying
commands, so explanations should say *why*, not just *what*.
